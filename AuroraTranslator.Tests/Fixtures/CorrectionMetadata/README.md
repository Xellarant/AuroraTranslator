# Correction metadata fixtures

Selected, otherwise unchanged definition blocks from the verified September 13,
2026 local hotfix files, retaining their original file info. `provenance.json`
records the source-relative paths and SHA-256 of each complete source file.

Original trailing whitespace is intentionally retained in the Staff and Tatsumi
definition blocks: correction fingerprints preserve text nodes, so these fixtures
must not be reformatted solely to satisfy whitespace lint.

- Devout: the corrected Zealot's Devotion grants and both target definitions.
- Tatsumi: the parent, Cloudstep, and renamed Heartening Breath.
- Musketball: the retained single-piece ammunition entry.
- Staff: the DMG 2024 Staff of Flowers with its corrected identity/source.

Tests add proposed metadata in memory or temporary files. Fixtures do not install
an active correction or implement mirroring/retirement.
